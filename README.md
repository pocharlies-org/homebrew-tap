# homebrew-tap

Homebrew tap for pocharlies-org apps.

```bash
brew tap pocharlies-org/tap
brew install --cask trisplit
```

| Cask | Description |
|---|---|
| `trisplit` | Grid window manager for macOS ([source](https://github.com/pocharlies-org/trisplit)) |

Casks are updated by `make release` in each app repository.
